# 牛来梦境视觉预设开发记录

日期：2026-08-20

## 需求

- 将《牛来》相关意象做成独立视觉预设，而不是并入无尽公路。
- 使用真实 3D 轮廓和场景层次，并随音乐响应。
- 预设卡片作者显示为 `Cyberforker`。

## 公开资料核对

- 公开剧情资料的稳定元素包括：初生小牛“牛来”、从荒漠飞来的云雀、草原中的成长梦境、森林守护，以及勇气和迁徙主题。
- 公开画面以电影海报、倒计时物料和观众屏摄为主，未找到带有明确再分发许可的官方 GLB、FBX 或贴图模型包。
- 参考入口：[Niu Lai film archive](https://niulai.wiki/en/)；[新浪剧情与制作资料](https://ent.sina.cn/2026-08-15/detail-ininiyyv2383001.d.html)。

因此仓库没有下载、描摹或打包电影截图、海报、角色模型和纹理。当前实现是依据公开故事元素制作的原创低多边形致敬场景。

## 实现

- 新增预设索引 `10`，显示名称为“牛来 / Dream Migration”。
- 使用 Three.js 基础几何体构建低多边形小牛、牛角、五官、四肢和可变形红披风。
- 使用独立几何体构建云雀及振翅动画。
- 使用实例化山体、草丛、河流、梦境粒子和三层墨色圆环构成固定对象池。
- 四个章节按时间循环并平滑过渡：荒漠摇篮曲、草原苏醒、森林守护、墨色梦境。
- 八个音域分别驱动地面回响；低频驱动奔跑和身体起伏，中高频驱动披风、云雀与粒子。
- 退出预设时释放所有几何体和材质，不保留电影或网络资源引用。

## 验证

- `tests/niulai-dream-preset.test.js` 覆盖索引、作者、四章节、八音域、对象池和离线边界。
- `scripts/check-niulai-dream-live.js` 覆盖宽屏、紧凑窗口、四章节、非空画布、主角投影位置、实际动画和作者卡片文本。
- 实机截图输出到 `output/playwright/niulai-dream-*.png`。
