# Mineradio 2.1.3（二改版）

Mineradio 是一款 Windows 桌面沉浸式音乐播放器：歌词舞台、粒子视觉、3D 歌单架、完整桌面模式与 Wallpaper Engine 壁纸支持，把搜索播放与视觉体验组合成更接近现场感的私人音乐空间。

本仓库为 **2.1.3 二改版**，由原作者 XxHuberrr 的 v2.1.0 二次开发而来，原版全部功能完整保留，并在此基础上新增多项实用功能与交互优化。

## 本版相对 v2.1.0 新增了什么（功能对比）

### 🎧 收听统计 + 年度报告
- 首页「今日聆听」可查看收听统计：总收听时长、本周/本月/年度对比、听歌时段分布、最爱歌曲与艺人 Top10

### 🕘 最近播放 + 一键恢复
- 本地记录最近 50 首播放历史，支持点击恢复播放（含进度续播），左侧「我的歌单」面板可随时查看

### 🖥️ 桌面悬浮窗
- 独立透明桌面小组件：实时时钟 + 日期 + 封面 + 歌名/歌手 + 当前歌词 + 可拖动彩色进度条
- 内置上一曲 / 暂停 / 下一曲 控制按钮，播放/暂停图标随状态切换

### ⌨️ 全局热键扩展
- 新增 `Ctrl+Alt+H`（收藏/取消收藏）、`Ctrl+Alt+Q`（队列显隐）、`Ctrl+Alt+↑/↓`（音量 ±5%），可在快捷键设置面板自定义

### 📊 队列面板信息条
- 播放列表顶部显示「共 N 首 · 总时长 · 下一首 · 预计播完时间」，随队列实时刷新

### 🎚️ 均衡器重构
- 均衡器按钮移至左侧播放面板 tab 行，点击后面板从按钮右侧展开（不影响左侧面板）
- 10 段 EQ + 5 预设 + 一键复位 + 响度归一化开关

### 🎨 界面与交互优化
- 底部状态栏重新布局：按钮间距统一、列宽自适应防重叠、窄窗口自动隐藏次要按钮
- 播放面板 tab 行方形圆角、悬浮窗按钮与均衡器按钮同规格
- 打开均衡器调试时左侧面板保持展开，不会自动收起

### 🔧 本次修复（v2.1.3 相对 v2.1.0 的修复与优化）
- **壁纸轮换过渡重构**：新增「燃烧殆尽」艺术化过渡——旧壁纸前景保留，多个不规则孔洞（真实烧纸毛边纹理）从随机位置慢慢扩大、余烬粒子上浮，直到烧尽露出新壁纸，全程无黑屏；切歌不再自动轮换壁纸（仅按设定间隔定时轮换）
- **用户存档扩展**：保存用户存档时，均衡器（10 段增益/预设/响度归一化）、壁纸轮换（开关/间隔/勾选集合）、睡眠定时等二改版新增功能设置会随存档一起保存与恢复
- **状态栏布局修复**：多轮修复按钮重叠——列宽改为内容自适应（min-content）从机制上杜绝挤压，按钮间距统一，窄窗口自动隐藏次要按钮
- **均衡器重构**：均衡器按钮移至左侧播放面板 tab 行（与当前队列/我的歌单/我的播客同排），点击后面板从右侧展开，10 段 EQ + 5 预设 + 复位 + 响度归一化；打开 EQ 调试时左侧面板保持展开不自动收起
- **桌面悬浮窗增强**：上一曲/暂停/下一曲控制、彩色可拖动进度条（即时响应）、播放/暂停图标随状态切换
- **全局热键扩展**：Ctrl+Alt+H 收藏 / Ctrl+Alt+Q 队列显隐 / Ctrl+Alt+↑↓ 音量
- **手势控制修复**：修复摄像头权限被拒（主窗口视频权限放行，音频不授予）
- **其他交互修复**：桌面歌词悬浮窗、本地音乐库选歌后浮层不关闭、歌词显示行数偶尔无效、预设/用户存档面板选项消失等若干问题

## 安装教程（Windows）

1. **下载安装包**：从本仓库 Release 下载 `Mineradio-2.1.3-Setup.exe`
2. **运行安装**：双击 Setup.exe，按提示安装（默认安装到 `%LOCALAPPDATA%\Programs\Mineradio`，自动创建桌面快捷方式）
3. **首次运行**：
   - 若 Windows SmartScreen 提示「已保护你的电脑」→ 点「更多信息」→「仍要运行」
   - 若杀毒软件误报 → 确认安装包来自本仓库 Release 后选择保留（Electron 未签名应用常见提示）
4. **手势控制（可选）**：若使用摄像头手势，需在 系统设置 → 隐私 → 摄像头 中允许桌面应用访问
5. **更新**：直接运行新版 Setup.exe 即可覆盖更新，播放数据与设置保留

> 小知识：`win-unpacked` 目录是免安装绿色版，直接运行 `Mineradio.exe` 也可使用（不创建快捷方式）。
